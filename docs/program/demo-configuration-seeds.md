# Demo configuration starter data

CoinLine can load a locally supplied demo configuration bundle when initializing a lab installation. The data is provided independently of the application repository; the importer and synthetic tests are shipped with CoinLine, not the original binary bundle.

Set `Platform__Seed__EnableDemoData=true` and `Platform__Seed__DemoConfigurationBundlePath` to the expanded bundle directory containing `manifest.json`. For Docker, set `COINLINE_DEMO_BUNDLE` to the local expanded directory and use the ordinary Compose configuration with the optional `docker/docker-compose.demo-seeds.yml` overlay. The data directory is mounted read-only; the importer writes verified table records to PostgreSQL. Leave the overlay off for installations that should not include demonstration data.

The manifest must identify the unframed message type, group, relative filename, complete record and body lengths, and SHA-256 digest. It must contain the 12 earlier and 27 later records. Each record starts with its type byte; its packed record length is checked against the matching registered table profile. Review-only metadata is not imported as a table. A missing, incompatible or digest-mismatched record refuses the bundle rather than silently importing a partial starter.

The result is two named starter drafts, **Demo starter, MTR 1.9** and **Demo starter, MTR 2.x**, not a mixed terminal configuration. On a new installation they appear as default starter drafts. When exactly one registered firmware version has the corresponding table profile, the starter targets that version; otherwise the operator selects an actual matching firmware. Restarting never overwrites an existing named starter or changes an assigned configuration, even if an operator has edited or published a copy of it.

The initially supplied earlier bundle contains an intentionally blank MT29. A successful hash check confirms the exact record was imported, not that it contains advertisements. Inspect the **Visible idle text messages (MT29)** count and the MT26 on-hook enable flag before copying a demo record into a working configuration. An enabled rotation with message 1 marked End sequence has no idle text advertisements. Retain the phone's working MT29 if the supplied demo record has no visible messages. The separately available graphical starter adds the bundled twenty image frames to a suitable graphical draft; neither the earlier blank text record nor the standard later starter contains MT131, MT132 or MT133.

These datasets contain examples of earlier and later tariffs, coin validation, display, schedules and other settings. The earlier tariff row 0 represents a 25-cent whole-call local charge; the next row is five cents per minute. The record containing the initial operating mode may be unset. Complete the actual terminal identity, management access, route references, operating mode, coin/card acceptance, carrier and missing required records before publishing. Reconstructed rates or numbering examples are not current geographic or commercial data. Protected account data and operational destinations must be configured separately. No starter is automatically published, assigned, or downloaded; verify terminal acknowledgement and actual behavior when preparing a site-specific copy.
