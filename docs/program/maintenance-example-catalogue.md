# Maintenance operation code catalogue

The original maintenance manuals (A0667039, January 1997, pages 4-1 through 4-2; P0883893, June 1998, page 5-2) list twelve example field-service operation codes. This is a suggested operator vocabulary, not a universal factory mapping. CoinLine keeps these examples separate from the four documented system maintenance events 996 through 999.

In **Field events**, open **Show reference** and review the historical maintenance examples. An operator with catalogue update permission can import the missing descriptions. Existing custom descriptions and intentionally cleared entries are not replaced. When demo seeding is enabled, missing examples are installed as editable operator settings at startup; other deployments can explicitly import them. A repeated import makes no changes.

Reports retain the actual numeric opcode and the neutral decoded meaning. A current operator description is shown alongside it in Field events and technician activity. Changing the catalogue changes the current interpretation, not the original report, its technician association, or the terminal's behavior. An unmatched or unclassified report remains visible. The catalogue does not issue Craft commands, configure local access, or prove that a reported service activity was performed.
