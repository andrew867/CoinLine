# Set up a phone or a configuration

1. In **Phones**, register the terminal with its actual line identity, installation site, firmware release and family. Select its [phone group memberships](phone-registration-groups.md) if appropriate. The registration is not a download.
2. In **Table sets**, choose **Start guided configuration setup**. Choose a published starting configuration or a designated default starter draft with the matching registered native firmware profile and the intended terminal family. Give the new draft a name. Default starters are marked as unpublished examples; the wizard copies them without modifying or publishing the original.
3. Choose card-only, coin-only, Multi-pay or unchanged payment mode. Choose an offline local tariff structure, the existing pricing, or a separately managed host real-time plan. For offline pricing, select the exact MT73 rate row already referenced by the local route. Choose the idle advertising mode: retain, text rotation, graphical rotation for an appropriate large-screen profile, or none. The graphical family defaults to graphical rotation; the wizard preserves MT29 text content and MT131–133 artwork while setting the independent enable flags. A normal terminal restart may be required after the changed records are delivered.
4. Review the intended record changes, the family checklist, payment availability and provisioning findings. Create the new draft only after reviewing the result. The source remains untouched and the new set is not assigned, published or queued automatically.
5. Open the resulting draft and complete the terminal-specific management access, local route, coin acceptance, card/carrier configuration, advertising and required tables. Correct any validation findings. Publish and use the normal assignment/preparation workflow, then check the terminal acknowledgement and actual operation.

The wizard deliberately does not invent a card range, coin calibration, rate-plan route, access identity or missing proprietary table. It copies a known configuration, modifies only the selected typed fields in MT26, MT73 and, where applicable, MT131, and retains every unrelated record and byte. A length-only or unregistered profile must be reviewed using the ordinary configuration tools first. Selecting host rating does not silently turn a terminal route into a host-rated one; review the route and published host rate plan separately.

If a suitable configuration is already published, the [initial configuration starter](phone-configuration-worksheet.md#start-an-unassigned-phone-from-a-published-configuration) in the new phone's individual configuration worksheet can stage its compatible records in one step. It uses the same reviewed assignment and explicit access-identity personalization as individual record choices. This does not modify the original set or queue a download.

For configurations shared between CoinLine installations, see [portable terminal configuration packages](portable-terminal-configuration.md). The import uses a reviewed local base set and creates a new draft, retaining local identity and protected configuration.
