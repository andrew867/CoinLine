# Visual prompt companion-language review

Visual prompt message positions must remain fixed across the language records. The worksheet supports the existing 140-row MT27/28 format and the 400-row MT85/86/98/99 format. Each row contains 20 display cells.

Open a prompt record in a table set and choose **Visual prompt worksheet**. The companion-language review lists the other appropriate records saved in that same set, with separate states for an available, missing, ambiguous or incompatible record. A complete target profile limits the list to its catalogued language record types.

For each compatible companion, the worksheet shows whether the corresponding wire row is blank, contains supported text, or contains unmapped glyphs. The **Blank in one language** filter finds positions with both blank and populated entries across the open record and its compatible companions. Edits staged in the open worksheet update the review immediately. The other records are read-only in this view; open each corresponding record or worksheet to make any deliberate translation changes.

A blank line can be intentional because different languages need different numbers of display lines. Unmapped glyphs are not considered missing text. The coverage review is therefore advisory and does not prevent publication, create translations, overwrite opaque cells or change companion revisions. It does not prove that a device supports a particular language or that the translated message will appear at the intended point in a call.
