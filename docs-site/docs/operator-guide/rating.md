# Rating

Publish a rate-plan version under Rate Plans and use the Rating Quote tool to verify a test destination. A firmware type 63 request uses the matched terminal's customer plan. Call Records shows the stored decision, and the detail view exposes the firmware request and response.

For a lab call, compare the terminal's displayed initial charge and the recorded quote. Use the NCC session correlation ID to locate the rate audit event. See [Rating and call flow](../protocols/rating-call-flow.md).
