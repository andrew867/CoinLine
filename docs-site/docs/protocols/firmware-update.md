# Firmware update

The registry holds packages, artifacts, checksums and compatibility rules. Firmware jobs provide simulation-first orchestration. The native terminal scheduler uses MT94, with the enabled or disabled scheduler record delivered through an ordinary management dialogue. A terminal may independently call the configured code-server destination when the schedule becomes due.

Native scheduled code-server connections have been observed on emulated terminals. In the retained observation, no application bytes were exchanged and the stored flash remained unchanged. The modem carrier, native code dialogue, image transfer, interrupted recovery, reboot and new configuration delivery remain qualification gates.

The [DLA transport adapter](../reference/firmware-dla-transport-adapter.md) provides host-side simulation and a separately gated XMODEM sender. A successful memory-loop simulation is not a successful native scheduled update. See [firmware jobs](../operator-guide/firmware-jobs.md) for the configuration transition review and the operator's next steps.
